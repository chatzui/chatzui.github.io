web-toast

A toast notification container that listens for web-toast-show events dispatched anywhere in the page. Toasts appear, persist for a configurable duration, then auto-dismiss. Multiple toasts stack.

When to use

  • Non-blocking success, error, or info messages after async operations
  • Background job status updates (file saved, export completed)
  • Transient feedback that should not interrupt the user’s workflow

Loading

<!-- Place once in your layout -->
<script type="module" src="/src/webs/apex/web-toast.js"></script>

Props

These props configure the toast container:

PropTypeDefaultDescription
timeoutnumber4000Default auto-dismiss delay in ms (can be overridden per toast)
positionstring'bottom-right'Where toasts appear: top-left | top-center | top-right | bottom-left | bottom-center | bottom-right
maxnumber5Maximum number of toasts visible simultaneously
uistring'modern'UI variant: modern | spatial

Showing a Toast

Dispatch a web-toast-show event from anywhere in the page:

window.dispatchEvent(new CustomEvent('web-toast-show', {
  detail: {
    type: 'success',          // 'info' | 'success' | 'warning' | 'error'
    title: 'Saved',           // optional title
    message: 'Changes saved successfully.',
    timeout: 3000,            // optional — overrides container default
  },
  bubbles: true,
  composed: true,
}));

Basic Example

<!-- Toast container in the layout -->
<web-toast position="bottom-right" timeout="4000"></web-toast>

<!-- Trigger a toast from a button -->
<web-button type="fill" id="save-btn">Save</web-button>

<script type="module" src="/src/webs/apex/web-toast.js"></script>
<script type="module" src="/src/webs/apex/web-button.js"></script>

<script>
  document.getElementById('save-btn').addEventListener('click', async () => {
    await saveData();
    window.dispatchEvent(new CustomEvent('web-toast-show', {
      detail: { type: 'success', message: 'Settings saved.' },
      bubbles: true,
    }));
  });
</script>

Advanced Examples

Error toast after a failed request:

try {
  await submitOrder();
  window.dispatchEvent(new CustomEvent('web-toast-show', {
    detail: { type: 'success', title: 'Order placed', message: 'You will receive a confirmation email.' },
    bubbles: true,
  }));
} catch (err) {
  window.dispatchEvent(new CustomEvent('web-toast-show', {
    detail: { type: 'error', title: 'Order failed', message: err.message, timeout: 8000 },
    bubbles: true,
  }));
}

Top-center position for form validations:

<web-toast position="top-center" timeout="3000" ui="spatial"></web-toast>
