web-button

A flexible button element supporting multiple visual styles, colors, sizes, loading and disabled states, and an optional badge rendering mode.

When to use

  • Primary actions (submit, save, buy)
  • Secondary or tertiary actions with lower visual weight (ghost, outline)
  • Status badges that need consistent button styling (mode="badge")
  • Buttons with async operations that need a loading spinner

Props

heightstring'md'Size: xs | sm | md | lg | xl
loadingbooleanfalseShow loading spinner and disable interactions
disabledbooleanfalseDisable the button
prefixstring''Icon or text prepended inside the button
suffixstring''Icon or text appended inside the button
modestring'button'Render as button or badge

Basic Example

<web-button type="fill" color="primary">Save Changes</web-button>
<web-button type="outline" color="secondary">Cancel</web-button>
<web-button type="ghost">Learn More</web-button>
<web-button type="soft" color="error">Delete</web-button>

Advanced Examples

Button with loading state:

<web-button type="fill" color="primary" loading id="submit-btn">
  Submitting...
</web-button>

<script>
  document.getElementById('submit-btn').addEventListener('click', async () => {
    const btn = document.getElementById('submit-btn');
    btn.setAttribute('loading', '');
    await saveData();
    btn.removeAttribute('loading');
  });
</script>

Pill button with prefix icon and badge mode:

<!-- Pill action button -->
<web-button type="fill" color="success" rounded prefix="✓">Confirmed</web-button>

<!-- Badge mode — renders as a styled span -->
<web-button mode="badge" color="warning" type="soft">Beta</web-button>
