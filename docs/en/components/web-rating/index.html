web-rating

Displays a star rating. Can be read-only (display only) or interactive (user can click to set a value). Fires an event when the rating changes.

When to use

  • Display average product or review ratings
  • Collect user satisfaction ratings in feedback forms
  • Show a user’s personal rating alongside a review

Loading

<script type="module" src="/src/webs/apex/web-rating.js"></script>

Props

PropTypeDefaultDescription
valuenumber0Current rating value (0 to max)
maxnumber5Maximum number of stars
readonlybooleanfalseDisable user interaction
sizestring'md'Star size: xs | sm | md | lg | xl
colorstring'warning'ApexUI color for filled stars
halfbooleanfalseAllow half-star increments
uistring'modern'UI variant: modern | spatial

Basic Example

<!-- Read-only display rating -->
<web-rating value="4" max="5" readonly></web-rating>

<!-- Interactive rating input -->
<web-rating value="0" max="5" id="user-rating"></web-rating>

<script type="module" src="/src/webs/apex/web-rating.js"></script>

Advanced Examples

Product card with average rating display:

<div style="display: flex; align-items: center; gap: 0.5rem;">
  <web-rating value="4.5" max="5" readonly half color="warning" size="sm"></web-rating>
  <span style="font-size: 0.875rem; color: var(--color-base-content);">4.5 (128 reviews)</span>
</div>

Feedback form with event handler:

<label>How would you rate your experience?</label>
<web-rating value="0" max="5" size="lg" id="feedback-rating"></web-rating>
<p id="rating-text" style="font-size: 0.875rem;"></p>

<script>
  const labels = ['', 'Poor', 'Fair', 'Good', 'Very good', 'Excellent'];
  document.getElementById('feedback-rating').addEventListener('web-rating-change', e => {
    document.getElementById('rating-text').textContent = labels[e.detail.value] ?? '';
  });
</script>
