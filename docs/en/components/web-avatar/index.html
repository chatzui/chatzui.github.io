web-avatar

Displays a user avatar with an image source or fallback initials. Supports multiple sizes, circle and square shapes, and an online status indicator.

When to use

  • Show user profile pictures in nav bars, comment threads, or user lists
  • Display initials when no profile image is available
  • Indicate user presence status (online, away, busy)

Loading

<script type="module" src="/src/webs/apex/web-avatar.js"></script>

Props

PropTypeDefaultDescription
srcstring''Image URL. If empty, shows initials fallback
namestring''User’s name — used to generate initials when src is empty
sizestring'md'Avatar size: xs | sm | md | lg | xl
shapestring'circle'Avatar shape: circle | square
statusstring''Presence indicator: online | away | busy — empty hides the dot
uistring'modern'UI variant: modern | spatial

Basic Example

<!-- With image -->
<web-avatar src="/images/user.jpg" name="Jane Doe" size="md"></web-avatar>

<!-- Initials fallback -->
<web-avatar name="John Smith" size="lg" shape="square"></web-avatar>

<!-- With status indicator -->
<web-avatar src="/images/alice.jpg" name="Alice" status="online"></web-avatar>

Advanced Examples

Avatar group (overlapping row):

<div style="display: flex; gap: -0.5rem;">
  <web-avatar src="/img/user1.jpg" name="User 1" size="sm" status="online"></web-avatar>
  <web-avatar src="/img/user2.jpg" name="User 2" size="sm" status="away"></web-avatar>
  <web-avatar name="User 3" size="sm"></web-avatar>
</div>

Large avatar in a profile header:

<web-avatar
  src="/images/profile.jpg"
  name="Alexandra Chen"
  size="xl"
  shape="circle"
  status="online"
  ui="spatial"
></web-avatar>
