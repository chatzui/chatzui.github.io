web-text

A styled text input or textarea. Supports a floating or top label, placeholder, disabled state, and inline error message. web-textarea is the multi-line variant sharing the same API.

When to use

  • Single-line text fields: name, email, search, password
  • Multi-line text areas: comments, descriptions, bios (web-textarea)
  • Form fields that need consistent theming and built-in error display

Loading

<!-- Text input -->
<script type="module" src="/src/webs/apex/web-text.js"></script>

<!-- Textarea (multi-line) -->
<script type="module" src="/src/webs/apex/web-textarea.js"></script>

Props

PropTypeDefaultDescription
labelstring''Label text displayed above or inside the field
placeholderstring''Placeholder text when the field is empty
valuestring''Current field value
typestring'text'Input type: text | email | password | number | search | url
disabledbooleanfalseDisable the field
readonlybooleanfalseMake the field read-only
errorstring''Error message shown below the field; empty = no error
requiredbooleanfalseMark the field as required
namestring''Input name attribute for form submission
rowsnumber4Number of visible rows (textarea only)
uistring'modern'UI variant: modern | spatial

Basic Example

<web-text
  label="Full Name"
  placeholder="Enter your full name"
  name="fullname"
  required
></web-text>

<web-text
  label="Email"
  type="email"
  placeholder="you@example.com"
  name="email"
></web-text>

<web-text
  label="Password"
  type="password"
  name="password"
  required
></web-text>

<script type="module" src="/src/webs/apex/web-text.js"></script>

Advanced Examples

Field with validation error:

<web-text
  label="Email"
  type="email"
  value="notanemail"
  error="Please enter a valid email address."
  id="email-field"
></web-text>

Textarea for comments:

<web-textarea
  label="Your Message"
  placeholder="Write your message here…"
  rows="6"
  name="message"
  required
></web-textarea>

<script type="module" src="/src/webs/apex/web-textarea.js"></script>

Read-only display field with spatial UI:

<web-text
  label="Account ID"
  value="USR-00142"
  readonly
  ui="spatial"
></web-text>
