web-gallery

Displays one image or a pipe-separated list of images. Supports lazy loading, rounded corners, and an optional float animation. Clicking an image opens it in a lightbox.

When to use

  • Product detail images or portfolio thumbnails
  • Blog post feature images or inline illustrations
  • Decorative images with subtle animation in hero sections

Loading

<script type="module" src="/src/webs/apex/web-gallery.js"></script>

Props

PropTypeDefaultDescription
srcstring''Single image URL, or multiple URLs separated by |
altstring''Alt text for the image(s)
loadingstring'lazy'Native loading hint: lazy | eager
roundedbooleanfalseApply border-radius to images
floatbooleanfalseApply subtle floating animation to the image
lightboxbooleantrueEnable click-to-expand lightbox
colsnumber3Number of columns when displaying multiple images
uistring'modern'UI variant: modern | spatial

Basic Example

<!-- Single image -->
<web-gallery src="/images/hero.jpg" alt="Hero image" rounded></web-gallery>

<!-- Multiple images -->
<web-gallery
  src="/images/photo1.jpg|/images/photo2.jpg|/images/photo3.jpg"
  alt="Gallery"
  cols="3"
  rounded
></web-gallery>

<script type="module" src="/src/webs/apex/web-gallery.js"></script>

Advanced Examples

Floating hero image with eager load:

<web-gallery
  src="/images/product-hero.jpg"
  alt="Product hero"
  loading="eager"
  float
  rounded
></web-gallery>

6-image portfolio grid without lightbox:

<web-gallery
  src="/img/work1.jpg|/img/work2.jpg|/img/work3.jpg|/img/work4.jpg|/img/work5.jpg|/img/work6.jpg"
  alt="Portfolio"
  cols="3"
  rounded
  lightbox="false"
></web-gallery>
