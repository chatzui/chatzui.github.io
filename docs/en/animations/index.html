Animations

Astro Micro provides a layered animation system: card entrance effects via CSS classes, text motion through web-letters, background animations via web-bg, and staggered queues for coordinated reveals.

Card Anime Classes

Apply entrance animations to web-boxs or individual web-box elements using the anime config key in a section config:

// src/sections/shop/config.js
export const productConfig = {
  anime: 'fade-up',
  // ...
};

Available classes:

ClassEffect
fade-upFade in while sliding up
fade-downFade in while sliding down
fade-leftFade in from the left
fade-rightFade in from the right
zoom-inScale up from 80% while fading in
zoom-outScale down from 120% while fading in
flip-x3D flip on the X axis
flip-y3D flip on the Y axis

These classes are driven by an Intersection Observer — the animation triggers when the element enters the viewport, not on page load.

animeQueue — Staggered Reveals

For coordinated entrance of multiple cards, use the animeQueue config to stagger each card’s delay:

const config = {
  anime: 'fade-up',
  animeQueue: {
    delay: 80,       // ms between each card
    max: 8,          // stop staggering after this many items
  },
  // ...
};

Cards beyond max all use the max * delay value, preventing very long delays on large datasets.

web-letters — Text Motion Effects

web-letters wraps text and animates each character or word individually:

<web-letters
  text="Welcome to Astro Micro"
  mode="chars"
  effect="slide-up"
  delay="30"
></web-letters>

<script type="module" src="/src/webs/apex/web-letters.js"></script>

web-letters Props

PropTypeDefaultDescription
textstring''The text to animate
modestring'chars'Split by chars or words
effectstring'fade'Animation effect: fade, slide-up, slide-down, blur
delaynumber50Stagger delay in ms between each unit
durationnumber400Duration of each unit’s animation in ms
triggerstring'viewport'viewport (Intersection Observer) or immediate

web-bg — Background Animations

web-bg renders animated decorative backgrounds behind a section:

<div style="position: relative;">
  <web-bg
    type="circle"
    total="6"
    move="float"
    tint="primary"
  ></web-bg>
  <!-- Content goes here -->
</div>

<script type="module" src="/src/webs/apex/web-bg.js"></script>

web-bg Props

PropTypeDefaultDescription
typestring'circle'Shape: circle | square | blob | circleOverlap
totalnumber4Number of background shapes to render
tintstring'primary'Color tint using a CSS variable name (e.g. primary, secondary)
movestring'float'Motion style: swap | float | pulse
patternstring''Optional overlay pattern: dots | grid | lines
opacitynumber0.15Shape opacity (0–1)
blurnumber80Blur radius in px applied to shapes

Move Types

ValueEffect
floatShapes drift slowly in random directions
swapShapes move between fixed positions
pulseShapes scale in and out rhythmically

Astro Page Transitions

Astro Micro uses Astro’s built-in View Transitions for smooth page navigation:

---
import { ClientRouter, fade } from 'astro:transitions';
---

<head>
  <ClientRouter />
</head>

<main transition:animate={fade({ duration: '0.3s' })}>
  <!-- Page content -->
</main>

For slide transitions between doc pages:

<article transition:animate="slide">
  <slot />
</article>

Combining Effects

A full section with background animation, staggered card entrance, and text motion:

---
const config = {
  anime: 'fade-up',
  animeQueue: { delay: 60, max: 6 },
  makes: [
    { opt: 'image', val: 'image' },
    { opt: 'text',  val: 'name' },
  ],
  tiers: [{ cols: 1, minWidth: 0 }, { cols: 3, minWidth: 1024 }],
};
---

<section style="position: relative; padding: 4rem 0;">
  <web-bg type="blob" total="5" move="float" tint="primary"></web-bg>

  <web-letters
    text="Our Products"
    mode="words"
    effect="slide-up"
    delay="80"
  ></web-letters>

  <web-boxs
    config={JSON.stringify(config)}
    dataApi="/api/products.json"
  ></web-boxs>
</section>

<script type="module" src="/src/webs/apex/web-bg.js"></script>
<script type="module" src="/src/webs/apex/web-letters.js"></script>
<script type="module" src="/src/webs/apex/web-boxs.js"></script>
