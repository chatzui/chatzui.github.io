web-bg

Component background trang trí với nhiều kiểu shape, gradient, pattern và animation. Thường dùng làm nền cho các section hoặc hero block.

Khi nào dùng

  • Tạo nền động cho hero section hoặc landing page
  • Thêm chiều sâu thị giác cho các card hoặc panel với glassmorphism (spatial)
  • Kết hợp pattern và gradient để làm nền đa dạng mà không cần ảnh

Cách tải

<script type="module" src="/src/webs/apex/web-bg.js"></script>

Props

PropKiểuMặc địnhMô tả
typestring'circle'Kiểu shape: circle | square | blob | circleOverlap | mesh | noise | wave
gradientbooleanfalseBật gradient overlay
tintstring''Màu tint — phải là CSS variable, ví dụ var(--color-primary)
totalnumber3Số lượng shape được tạo
movestring''Kiểu animation: swap | float | pulse
patternstring''Pattern nền, ví dụ dot~24 hoặc grid~32
huestring'transparent'Màu nền tổng thể
degnumber180Góc gradient (độ)
fixedbooleanfalseCố định vị trí (position: fixed)
roundedbooleanfalseBo góc các shape
spatialbooleanfalseBật hiệu ứng glassmorphism (backdrop blur)

Lưu ý màu sắc: Prop tint và hue phải dùng CSS variable từ hệ thống (ví dụ var(--color-primary)). Không hardcode giá trị hex hay rgb.

Ví dụ cơ bản

<web-bg type="circleOverlap" tint="var(--color-primary)" total="3" move="float" deg="180"></web-bg>
<web-bg type="mesh" gradient pattern="dot~24" spatial></web-bg>

Ví dụ nâng cao

Background với animation pulse và pattern grid:

<div style="position:relative; height:400px; overflow:hidden;">
  <web-bg
    type="blob"
    tint="var(--color-secondary)"
    total="4"
    move="pulse"
    gradient
    pattern="grid~32"
    rounded
  ></web-bg>
  <div style="position:relative; z-index:1;">Nội dung bên trên</div>
</div>

Background cố định toàn trang với glassmorphism:

<web-bg
  type="wave"
  tint="var(--color-accent)"
  move="float"
  fixed
  spatial
  deg="135"
></web-bg>
