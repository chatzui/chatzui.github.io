Nạp kiến thứcLoad knowledge

Trợ lý chỉ trả lời từ các dòng kiến thức của bạn — mỗi dòng phải tự đủ ý (tiêu đề + nội dung). Có 2 cách nạp, đều vào cùng một kho: The assistant answers only from your knowledge rows — each must be self-contained (title + content). Two ways in, both into the same base:

1. Từ API JSON, trong Cài đặt1. From a JSON API, in Settings

  1. Mở /system/ecommerce (trang lĩnh vực của bạn), đăng nhập bằng node Tài khoản (góc phải trên) đúng tài khoản đã mua gói. Open /system/ecommerce (your sector's page) and sign in with the Account node (top right) — the account that bought the plan.
  2. Mở node Tư vấn → nút ⚙ trên đầu khung chat → Nạp từ API & MCP. Open the Consult node → the ⚙ button atop the chat → Load from API & MCP.
  3. Dán đường dẫn, chọn Loại (product, faq, law, post, technical, finance, medical, other hoặc tự đặt) → Xem trước (5 mục mẫu + cách map) → Nạp dữ liệu. Paste the link, pick a Type (product, faq, law, post, technical, finance, medical, other or your own) → Preview (5 samples + mapping) → Load.
